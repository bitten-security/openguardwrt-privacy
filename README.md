# OpenGuardWRT — Privacy Policy

This repository holds the published Privacy Policy for
[OpenGuardWRT](https://github.com/bitten-security/OpenGuardWRT), a
read-only dashboard app for OpenWrt routers and AdGuard Home.

**Live page:** https://bitten-security.github.io/openguardwrt-privacy/

The app has no server of its own — it talks only to the router/AdGuard
Home instance the user configures. No data is collected, sold, or shared
with third parties. See the live page above for the full policy.

`index.html` is the only file that matters here; it's served as-is via
GitHub Pages. Edit it and push to `main` to update the published policy.
